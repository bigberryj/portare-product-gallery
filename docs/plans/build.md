## Shared frontend markup contract
PHP render root `.ppg` with attributes `data-ppg`, `data-product-id`, `data-text-side="left|right"`, `data-autoplay="0|1"`, `data-interval` milliseconds, `data-transition="fade|slide|none"`, `data-duration` milliseconds, `data-load-effect="none|fade|rise"`; inline CSS variables sanitized and supplied by settings.
Children: `.ppg-copy` with `.ppg-title`, `.ppg-description` (initial html), `.ppg-quote` data-align left/center/right. `.ppg-media` contains `.ppg-stage` img `.ppg-main-image`; `.ppg-toolbar` buttons `.ppg-prev`, `.ppg-play`, `.ppg-next`; `.ppg-thumbnails` with button `.ppg-thumb` data-index and aria-pressed. `.ppg-status` role status, `.ppg-error` role alert hidden. Script `.ppg-data` type application/json containing {slides:[{id,src,srcset,sizes,alt,width,height,description,x,y,zoom}],defaultDescription:string}. JSON HEX flags protect script context. Use DOM template/data descriptions sanitized server-side. CSS variables: --ppg-copy-width (30%), --ppg-gap (36px), --ppg-radius (32px), --ppg-thumb-radius (8px), --ppg-thumb-gap (24px), --ppg-title-size (22px), --ppg-text-size (14px), --ppg-line-height (1.8), --ppg-font (inherit), --ppg-text-color (#16354b), --ppg-title-color (#111111), --ppg-accent (#7eaf80), --ppg-duration (250ms), --ppg-ratio (1.64).
